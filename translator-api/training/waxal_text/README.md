# WAXAL sentences (Kikuyu, Dholuo, Swahili)

Sentences from the text of [google/WaxalNLP](https://huggingface.co/datasets/google/WaxalNLP) TTS recordings
(`kik_tts`, `luo_tts`, `swa_tts`), split into sentences of 3 to 40 words and de-duplicated by `waxal.py --download`.
Shipped here so a slow connection doesn't have to read ~2.8 GB of audio files to get 1.4 MB of text.
